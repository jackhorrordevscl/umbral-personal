# Frontend — Umbral - RCE

Interfaz React del sistema de gestión de fichas clínicas. Documentación
completa del proyecto (instalación, variables de entorno, endpoints,
compliance) en el [README raíz](../README.md).

## Comandos

```bash
npm install --legacy-peer-deps
npm run dev        # desarrollo (http://localhost:5173)
npm run build       # typecheck + build de producción
npm run lint         # lint
npm run preview      # previsualizar el build
npm run test         # tests unitarios (Vitest)
npm run test:watch   # tests en modo watch
npm run test:cov     # tests con cobertura
npm run test:e2e     # e2e con Playwright (no corre en CI)
```
